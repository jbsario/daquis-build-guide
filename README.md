# Daquis Residence build guide

Interactive one-page guide for the proposed 3-storey residence at Blk 1 Lot 49 Sandari Batulao, Nasugbu, Batangas.

- 24-step rotatable 3D build: layout to finished house
- Structure, plumbing and electrical from the D.V. Fallarme construction plans
- Dimensions, tap-for-details on every member, materials per step
- Plumbing and electrical sheets with zoom

Static site: no build step. `index.html` plus the `sheets/` images.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. In Vercel: Add New → Project → import the repo → Framework preset "Other" → Deploy.

Quantities are model estimates, not a bill of quantities. Build only from the signed plans.
